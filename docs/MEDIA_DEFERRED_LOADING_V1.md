# Carregamento de mídias sob demanda — V1 (#1278)
Base main independente das PRs de recibo/inventário. MediaCarousel já renderiza só o slide corrente; manter layout, navegação, controles, sem autoplay. Imagem usa lazy loading nativo e decoding async. Vídeo mantém o elemento sem src até interseção com viewport + margem vertical de 200px; após isso solicita metadata, com controles originais. Não promete limite de bytes por metadata (depende de browser, codec e servidor). Browser sem IntersectionObserver usa fallback imediato; desmontagem cancela callback; mudança de URL remonta o vídeo. Nenhuma nova dependência, regra Firebase, API ou serviço pago. Sem cache compartilhado ou modificação de URL/autoridade. 
Testes unitários do observador e contratos na suíte social existente. Homologação pendente: Android/Chromium, medir requisições/bytes antes de scroll e após visibilidade, navegação entre slides, início de reprodução, conexão lenta, erro de mídia, cards visíveis e distantes, regressão visual. Sem medição de economia de rede ou bateria ainda. Não implantar/mergear antes de aceite.
