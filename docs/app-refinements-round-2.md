# Ajustes do app — rodada 2

Este documento acompanha o PR de continuidade aberto após o merge do PR #135.

## Objetivo

Centralizar os próximos ajustes visuais, funcionais e de navegação do Kyrub em uma branch isolada, com validação por preview autenticada antes de qualquer novo merge na `main`.

## Fluxo de trabalho

1. Aplicar uma alteração por vez ou em pequenos pacotes relacionados.
2. Validar `Application build` e `Validate Kyrub`.
3. Publicar no preview autenticado para revisão mobile.
4. Manter o PR em rascunho até aprovação explícita para merge.
