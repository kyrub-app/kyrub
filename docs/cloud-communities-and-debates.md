# Comunidades e Debates multiusuário

Esta etapa substitui o protótipo local de Comunidades por persistência real no Firebase.

## Escopo

- comunidades compartilhadas entre perfis;
- membros vinculados ao Firebase Auth;
- mural compartilhado;
- Discussões renomeadas para Debates;
- comentários em tempo real dentro dos debates;
- capa armazenada no Firebase Storage;
- regras e testes de segurança do Firestore e Storage;
- migração assistida dos dados locais quando tecnicamente segura.

O trabalho permanece em PR de rascunho até validação no preview autenticado e autorização explícita para merge.
