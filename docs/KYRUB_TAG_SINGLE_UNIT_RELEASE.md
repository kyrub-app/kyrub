# Liberação individual para teste físico
A versão 95b8ec079842 em produção criou estoque permanente retido e confirmou leituras apenas no documento do lote. Não havia operação que mudasse manufacturingState para released. Esta correção permite exclusivamente a unidade selecionada pela configuração existente, com lote permanente correspondente, leitura NDEF registrada e papel Super Admin verificado em transação. Não cria tags, não altera titularidade, não sobrescreve NFC. A ação é idempotente e auditada. O responsável acessa Histórico de tags validadas/ seção Teste de ativação no Control Plane e confirma a liberação. Se a unidade não tiver readback registrado, retomar pendência e fazer apenas leitura. Sem alteração de produção antes de aprovação. O código não habilita as demais unidades nem altera a PR #1346.
