# ERP — cinco centros de custo fixos
Decisão de 25/11/2026, issue #1278. Substitui proposta de cadastro/arquivamento das #1298/#1299, ainda não implantada. Taxonomia única: cc_infrastructure Infraestrutura, cc_commercial Comercial, cc_administrative Administrativo, cc_products Produtos, cc_logistics Logística. Sem cadastro customizado, coleção de configuração, leitura adicional ou ação de arquivo. Seleção obrigatória no formulário manual; API aceita omissão/blank somente por compatibilidade com clientes antigos, não infere classificação. ID inválido é rejeitado, nome vem do catálogo servidor. Snapshots legados permanecem legíveis, sem migração e sem converter nomes em IDs. RH/compras permanecem sem classificação automática. Centro é dimensão gerencial, não comprovação de pagamento. 
Control Plane: leitor experimental por classificação fixa, designação canônica oficial no servidor, autorização finance/super_admin, transação somente leitura, mês São Paulo, consulta paidAt no ERP oficial (máximo 500 linhas, excedente indisponível). Soma exclusivamente registros pagos com ID cc_infrastructure; comercial e outras lojas excluídos; ausência não vira zero. Não requer referência manual adicional para esta apuração observada, não representa custo real conciliado ou MAU. Documentos, FX, duplicatas de faturas, cobertura e liquidação continuam gates para métrica definitiva. Leitor anterior por referências também exige ID fixo. Sem endpoint, coleta real, migração ou deploy. #1302 build aprovado; #1303 build falhou por asserção estática antiga do verificador; corrigida nesta cadeia, CI pendente. Não remover dados de registry de eventual ambiente de teste. Sem execução de produção.
