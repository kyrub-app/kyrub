# FinOps — teste integrado de autenticação e MAU (V1)
Base candidato #1293. Refatora somente composição do receiver; rota HTTP continua usando verificador Firebase real, relógio do servidor, transporte e logger existentes. Nenhum parâmetro HTTP seleciona dependências. Teste isolado usa par RSA efêmero, resposta de certificados públicos substituída apenas no processo de teste, verificador real valida assinatura/issuer/audience/expiry. Admin SDK conectado exclusivamente ao emulador loopback com projeto de testes. Cenários: sem token, assinatura errada, audience errada, expirado, oito solicitações concorrentes, UID adulterado no corpo, data cliente antiga, atividade não elegível, segunda conta, virada de mês e count agregado, realMau null. Não constitui E2E HTTP/browser com Firebase Auth real; nem prova revogação, cobertura, classificação de contas de teste ou autorização administrativa HTTP completa. Nenhum bypass de autenticação, segredo real, regra, serviço novo ou coleta em produção. CI pendente. A próxima etapa é homologação browser/HTTP isolada e governança de retenção, antes de qualquer ativação.
