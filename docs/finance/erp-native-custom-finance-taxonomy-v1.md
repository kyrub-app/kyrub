# ERP — opções nativas e personalizadas de classificação financeira
Decisão do proprietário: cinco centros nativos fixos, categorias nativas atuais preservadas; botão + para adicionar, editar e excluir somente opções personalizadas. RH/folha permanece restrito à origem RH. Uma configuração server-only por loja (financeConfig/taxonomy), até 100 personalizadas ativas por dimensão; nomes reservados nativos, duplicidade sem distinção de acento/caixa. ID aleatório com prefixo reservado a custom, servidor valida no tenant após autorização do proprietário e em transação com lançamento. Excluir remove apenas opção do cadastro, nunca conta; snapshot id/nome histórico permanece e não é reclassificado. Renomear afeta somente futuras contas, relatório distingue versões históricas de nomes. Categoria personalizada tem categoria contábil base other e snapshot separado, não contorna regras de RH/estoque; relatórios por período mostram o nome personalizado. Nenhuma nova consulta por lançamento nativo; uma leitura de configuração no Financeiro, custos de leitura/escrita em personalização. Control Plane continua reconhecendo somente ID nativo Infraestrutura na Loja Oficial, não pelo nome. Sem migração, produção ou deploy. CI, teste de integração HTTP e visual pendentes; não se presume validação das PRs anteriores.
